## What a tech pack does

A tech pack is the set of instructions a factory uses to make your garment. It replaces dozens of emails with one file. When it is complete, the factory can price the style, order fabric and sew a sample that looks like what you pictured.

When it is thin, the factory guesses. Guesses cost you a sample round, and each round adds a week or more to your launch.

This guide shows how to create a tech pack that answers the factory's questions before they ask them.

## The eight parts of a tech pack

The table at the top of this page lists the parts. Here is what each one needs.

### Cover page

Put the style name and number, season, size range, colourways and the date of this version on the first page. Add a small front sketch so anyone can see which garment the file is about. Change the version date every time you edit the file.

### Flat sketches

Flats are clean line drawings of the garment laid flat, front and back. Draw them to scale, with seams, stitching and pockets where they really sit. Add close-ups for collars, cuffs, pocket shapes and any detail that is hard to see at full size.

Flats are not fashion drawings. Skip poses, shading and models. A factory needs to count panels and read seam lines.

### Points of measure

Points of measure, often shortened to POMs, show exactly where each measurement is taken. Give each one a code, such as A for chest width and B for body length, and mark the codes on a flat sketch.

Common points of measure on a tee:

| Code | Point of measure | How to take it |
| --- | --- | --- |
| A | Chest width | Across the body, one centimetre below the armhole |
| B | Body length | From the high point shoulder down to the hem |
| C | Shoulder width | Seam to seam across the back |
| D | Sleeve length | From the shoulder seam to the sleeve hem |
| E | Sleeve opening | Straight across the hem of the sleeve |
| F | Neck width | Seam to seam across the neck opening |
| G | Hem width | Straight across the bottom hem |

Measure flat, half the circumference, unless you say otherwise. State it on the page.

### Size chart

The size chart lists every point of measure for every size. Start with one base size, usually a medium, and fill in the rest. Add a tolerance to each line, such as plus or minus one centimetre for chest, so the factory knows how close is close enough.

If you are not sure how sizes should step up, give the base size and let the pattern maker suggest the grading. Our [pattern making service](/pattern-making-service/) explains how grading works.

### Materials list

List every fabric, lining, thread, zip, button, drawcord, elastic and label. For each, give the type, weight or size, colour and where it goes. Fabric needs fibre content and weight. A zip needs length, tooth type and puller.

This list is how the factory prices your garment and books materials. A missing trim means a missing cost on the quote.

### Artwork

Add every print or embroidery file. For each one, give the method, the finished size and the position measured from a fixed point, such as eight centimetres below the neck seam. Give each ink or thread colour as a Pantone code.

### Construction notes

Note seam types, stitch counts per inch, hem widths and finishes. You do not need every detail for a first sample. The factory can suggest standard methods. Note anything you care about, such as a twin-needle hem or a bound neck.

### Packing

Say how each garment is folded, which bag it goes in, which tags go where, and how cartons are marked. Packing errors are the most common surprise at shipment, and the cheapest to prevent.

## How to create a tech pack, step by step

1. **Collect references.** Gather photos and, ideally, one garment that fits the way you want.
2. **Draw the flats.** Front and back first, then details.
3. **Measure the reference garment.** Lay it flat and take every point of measure. This becomes your base size.
4. **Build the size chart.** Add the other sizes and a tolerance for each line.
5. **List the materials.** Walk through the garment from collar to hem and write down every part.
6. **Add artwork and labels.** Files, sizes, positions and colours.
7. **Add packing.** Folding, bags, tags and carton marks.
8. **Check and date it.** Run the checklist below, then save as one PDF with a version date.

Follow these steps and the factory can work from your file without a long thread of questions.

## Tech pack checklist

Use this tech pack checklist before you send the file:

- Every page shows the style name and version date
- Front and back flats match each other and the materials list
- Every point of measure has a code on the sketch and a line in the size chart
- Every size chart line has a tolerance
- Every colour is a Pantone code or a physical swatch reference
- Every artwork has a method, size and position
- Every label has content and placement
- Packing is described down to the carton
- File names include style and version

## Common tech pack mistakes

These tech pack mistakes cause most extra sample rounds:

| Mistake | What happens | Fix |
| --- | --- | --- |
| Colours named, not coded | "Navy" comes back too bright or too grey | Use Pantone codes or send a swatch |
| No tolerances | Every small difference becomes a debate | Add plus or minus values per line |
| Artwork with no position | Logos land too high or too low | Measure from a fixed point |
| Sketch and size chart disagree | Factory has to guess which is right | Check both before sending |
| No version date | Two people work from different files | Date every version |
| Trims left out | Quote is too low, then rises | List every part in the materials list |

## Do you need a tech pack template?

A tech pack template saves time, but it does not make the content right. What matters is that every page is complete and consistent. A spreadsheet with tabs for each part works well for a first collection. Larger brands often use product software that exports a PDF.

Whatever you use, keep one master file per style and never edit a file that is already with the factory without changing the version date.
