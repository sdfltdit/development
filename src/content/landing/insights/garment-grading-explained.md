## What garment grading is

You fit a sample in one size until it is right. Then you need the same garment in five, six or more sizes. Garment grading is the pattern work that gets you there.

The pattern maker takes the approved **base size** pattern and moves each point outwards for larger sizes and inwards for smaller ones, by set amounts. The result is a set of patterns, one per size, that keep the same shape and proportions.

## The base size

The base size is the size you sample and fit first. Most brands choose a size in the middle of their range, such as a medium.

Grading from the middle is safer. Any small error spreads both ways instead of growing steadily towards the largest size.

## Grade rules

Grade rules say how much each measurement changes from one size to the next. There is a rule for every point of measure on your size chart.

### Typical size increments for a knit tee

| Point of measure | Typical change per size |
| --- | --- |
| Chest width, measured flat | About 2 to 2.5 cm (4 to 5 cm all round) |
| Body length | About 1.5 to 2 cm |
| Shoulder width | About 1 to 1.5 cm |
| Sleeve length | About 0.5 to 1 cm |
| Neck width | About 0.5 to 1 cm |
| Hem width, measured flat | About 2 to 2.5 cm |

These size increments are a common starting point, not a rule. A brand for tall customers grades length more. An oversized brand may grade width more than length.

## Break points

A break point is where size increments change. Many ranges use one step for XS to L, then bigger steps from XL upwards, because bodies widen faster at larger sizes.

| Range | Chest change per size, all round |
| --- | --- |
| XS to L | About 4 to 5 cm |
| XL and up | About 5 to 6 cm |

Set break points on purpose. Without them, larger sizes often come out too tight.

## Grading and fit

Grading and fit are linked. A perfect base size can still produce poor larger sizes if the grade rules are too simple.

Common problems:

| Problem | Cause | Fix |
| --- | --- | --- |
| Large sizes too long | Length graded as fast as width | Smaller length steps on larger sizes |
| Armholes too tight on XL | Armhole not graded with chest | Grade armhole depth and width together |
| Necklines too wide on small sizes | Neck graded too much | Smaller neck steps |
| Shoulders falling off on large sizes | Shoulder graded too fast | Grade shoulders less than chest |

## Extended sizes

Plus and extended sizes are not just bigger versions of a medium. Body shape changes, so many brands set a second base size for the extended range and fit it on a real body.

## How to check garment grading

1. **Fit the base size** until it is approved.
2. **Grade the pattern** with your grade rules.
3. **Make a size set.** Sew the smallest and largest sizes, plus any break point size.
4. **Measure and try on.** Check each against the size chart and on a fitter if possible.
5. **Adjust the rules** where a size looks wrong, then lock the graded pattern.
