## Why colour codes cause so many problems

Colour is one of the most common reasons for delays in clothing production. A brand picks a colour on screen, sends the code, and the first sample looks wrong. Most of the time, the problem is not the dyeing. It is the code.

This guide explains hex code vs Pantone TCX and the other colour systems, and how to give a factory a colour it can match.

## What a hex code is

A hex code, such as #1F3A5F, describes a colour made of red, green and blue light on a screen. It is perfect for websites and apps. It is not built for fabric, because:

- every monitor and phone shows it a little differently
- screen brightness and settings change the look
- light from a screen is not the same as light bouncing off fabric
- there is no physical sample to hold and compare

A factory can turn a hex code into a dye recipe, but it is a starting guess, not a target.

## What Pantone TCX is

Pantone TCX is part of the Pantone textile range. Each colour is a dyed cotton swatch with a code, such as 19-4052 TCX. Because it is a real piece of dyed cotton, both buyer and factory can hold it under the same light and judge the same colour.

That is why TCX is the usual colour standard in clothing.

## Hex code vs Pantone TCX side by side

| Point | Hex code | Pantone TCX |
| --- | --- | --- |
| What it is | Screen colour made of light | Dyed cotton swatch |
| Looks the same everywhere | No | Yes, under the same light |
| Made for | Websites, apps, screens | Textiles and clothing |
| Physical sample | No | Yes |
| Use in a tech pack | Rough guide only | Main colour standard |

## Pantone TCX vs TPG and PMS

Pantone has several systems, and mixing them up causes errors.

| System | Material | Best for |
| --- | --- | --- |
| TCX | Dyed cotton swatch | Fabric and clothing colour standards |
| TPG | Printed paper chip from the textile range | Mood boards and quick checks |
| PMS | Ink on paper, coated or uncoated | Logos, packaging, swing tags, print |

On Pantone TCX vs TPG, TCX shows the colour on fabric, so it wins for dyeing. TPG is handy for design work but paper reflects light differently.

PMS is a graphic design system. Use it for printed labels, swing tags and packaging, not for dyed fabric. A PMS code and a TCX code with similar numbers are not the same colour.

## Cotton vs polyester colour

The same colour code gives a different result on different fibres. On cotton vs polyester colour, there are three main reasons:

1. **Different dyes.** Cotton uses reactive dyes, while polyester uses disperse dyes at high heat.
2. **Different surfaces.** Polyester often has more shine, so colours can look brighter.
3. **Different light.** A match under shop light may look off in daylight.

So a hoodie body in cotton fleece and a nylon drawcord in the same colour need separate approvals. Our guide on [shade variation](/insights/shade-variation-explained/) explains how this affects bulk.

## How to write a Pantone colour in a tech pack

When you add a Pantone colour in a tech pack, follow these steps:

1. **Write the full code with its suffix,** such as 19-4052 TCX, not just 19-4052.
2. **Place it next to each part,** such as body, rib, drawcord and print.
3. **Name the fabric** the colour is for.
4. **Add a swatch photo** for reference, while knowing photos also shift colour.
5. **Send a physical swatch** for key colours if you can.
6. **Say which light** to judge under, such as D65 daylight.

Our [guide to creating a tech pack](/how-to-create-a-tech-pack/) covers the rest of the document.

## A physical colour standard beats any code

The most reliable way to brief colour is a physical colour standard. That can be a Pantone TCX swatch, a fabric piece, a garment or even a yarn. The factory then makes [lab dips](/insights/lab-dip-explained/), small dyed samples that you approve before bulk fabric is dyed.
